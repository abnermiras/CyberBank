# CyberBank — UI Prototype

Primeiro protótipo navegável do CyberBank.

## Fluxo implementado

`Login → Dashboard`

`Login → Cadastro → Login`

Os dados do dashboard são fictícios e existem apenas para validar composição visual, navegação e futuras decisões de negócio.

## Direção visual

A interface combina referências do universo **Cyberpunk 2077** com uma identidade própria do CyberBank:

- fundo quase preto e atmosfera de terminal;
- amarelo ácido como cor de ação/alerta;
- cyan e magenta como cores de sinalização tecnológica;
- tipografia condensada para títulos e monoespaçada para telemetria;
- painéis angulares em vez de cards arredondados;
- scanlines, grid, glow, glitch e microtextos de sistema;
- linguagem de terminal e de infraestrutura financeira;
- estética híbrida entre interface corporativa, HUD e equipamento eletrônico retro-futurista.

A direção é deliberadamente próxima do espírito visual de Night City, mas sem reutilizar logotipos, personagens, artes ou assets do jogo. A própria CD PROJEKT RED descreve estilos como Entropism, Kitsch, Neomilitarism e Neokitsch, enquanto a direção de UI de Cyberpunk 2077 foi influenciada por eletrônica dos anos 1980, displays HiFi e HUDs com sensação física. Essas referências foram usadas como princípios, não como assets.
